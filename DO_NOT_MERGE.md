# Do Not Merge

This branch, `winstride`, is a full import of the `Ofish-Ofish/WinStride` repository into `UML-Cyber-Security/ccdc2026-internal`.

It exists to preserve the complete WinStride codebase in one place, including the original [LICENSE](LICENSE).

This branch is not intended to be merged into `main` or any other working branch of `ccdc2026-internal`.
